What we ship

Doré, the always-on reserve-verification product.

Stablecoin issuers publish claims. Doré checks those claims against on-chain reality, every figure traceable to a source. Built on Hermes, our runtime. Deployed inside regulated programmes. Evidence ready for an auditor on a bank-holiday morning.

01
Doré In production

Reserve verification, sanctions, redemption, cited.

The product reconciles what an issuer attests against what the chains actually show. Multi-chain supply reads, cross-RPC corroboration, OFAC SDN screening, redemption- capacity assessment. Every figure carries provenance: the claim, the sources checked against, the timestamp, the block, the verification status.

The model proposes. Deterministic code disposes. No displayed figure is ever invented by a language model. Sanity bounds gate every value before it reaches the analyst's view. When data cannot be verified, the surface says so plainly. An honest gap is a finding.

  • Three compliance surfaces. Attestation analysis, sanctions screening, redemption capacity.
  • Two honest coverage numbers. Attested coverage at the attestation date, live coverage against current on-chain supply, drift surfaced between them.
  • Multi-source verification. Each figure carries the channel that found it: issuer transparency page, on-chain RPC consensus, attestation PDF, or web-discovered candidate awaiting a second source. Search proposes; verified sources dispose.
  • Background data layer. A canary thread every six hours re-resolves every attestation URL, re-checks every corpus source, auto-verifies every on-chain contract, and proposes replacements when sources rot. The cache users read from is always warm.
  • Immutable audit trail. Every analysis records append-only, time-series facts with full provenance, queryable point-in-time. The same shape will hold the next claim type without a schema rewrite.
  • Hermes, the analyst. A constrained conversational agent that answers only from the verified fact store through a read-only tool boundary, cites every figure, and refuses when it cannot ground an answer.
  • Compendium view. A live ledger of the data layer itself — provenance of every URL, health of every regulatory source, the background thread's recent work — written as docs, refreshable.

02
Hermes Runtime

The runtime our products run on, policy-bound from the start.

Hermes is the agent runtime. Doré runs on it. Future products run on it. Policy is versioned. Dual approval gates on policy changes. Kill switches configured for the head of compliance and the CFO. Evidence retention configured per MiCA, the GENIUS Act, and equivalent regimes.

The agent reaches the system through a read-only tool boundary, not raw database access. Every tool call is audit-logged. Native runtimes (shell, code execution, unrestricted web) are switched off by default. Curation decisions — what data to trust, what address to mark verified — stay with humans. The agent reads and recommends. The human decides.
