Doré

Stablecoins, verified.

Doré reads every attestation an issuer publishes and reconciles it against the chains live, every six hours. Every figure traces back to its source. Every claim cites the regulation it answers to. Nothing the system displays is invented by a model.

Doré Live · v1.0 · in design-partner deployment

The verification surface, cited end to end.

Three views on top of one verification core. Attestation analysis reconciles reserves against on-chain supply, surfaces drift, and reports coverage at both the attestation date and right now. Sanctions screening runs every deployment address against the OFAC SDN list with tamper-detection on the feed. Redemption capacity tiers reserves by speed and reports what the issuer can settle today.

Every analysis carries the channel that produced it. Multi-RPC corroboration per chain, the attestation PDF, an immutable fact-store row, and where relevant the secondary web references the agent considered. Search proposes. Deterministic code disposes. An honest gap is a finding, not a failure.

Hermes The runtime underneath every Doré surface

Hermes, the runtime underneath.

Hermes is the agent runtime Doré sits on. Policy is versioned. Dual approval gates guard every policy change. Kill switches are configured per role so the head of compliance, the CFO, and the on-call operator each have a button. Evidence retention is configured per MiCA, the GENIUS Act, and equivalent regimes from the first deploy.

The agent reaches the system through a read-only tool boundary. Eight tools. Every call audit-logged. Native shell, code execution, and unrestricted web are switched off by default. Curation decisions stay with humans: which data to trust, which address to mark verified. The agent reads and recommends. The human decides.

What comes next

The verification core is object-agnostic. The same engine that reconciles an issuer's reserve claim against on-chain reality reconciles an agent's spending claim against settlement reality. The fact store schema already holds both. The flagship stays Doré. The runtime stays Hermes. The next surface lands on the same discipline.
