Bold Reinvention · First-Screen Clarity

Three directions for what Rayleigh Stark looks like in 2026.

The current first screen leads with a handwritten flourish and an auto-rotating service carousel. It reads more design-studio than operator-led firm. Each prototype below picks a different answer to the same brief: what is Rayleigh Stark, and who is it for — in under three seconds?

Reference points · what serious B2B looks like in 2025–26

Trend 01
Console / terminal aesthetic. Mono type, status lines, live ticker.
Linear, Vercel, Mercury, Brex, Bloomberg-adjacent finance brands. Signals competence by looking like the tools the customer already trusts.
Trend 02
Editorial gravity. Massive serif statements, manifesto-as-hero, newsprint structure.
Anthropic, post-redesign Sequoia, a16z, Stripe ship pages, Carta. POV signals seriousness; restraint signals scarcity.
Trend 03
Show the surface, don't say it. The hero IS the system diagram or product UI.
Retool, Replit, Pylon, the new wave of infra brands. The visual carries the positioning so the copy can be short.
Trend 04
Specificity over slogans. Named contexts in the hero — not "complex systems," but trading desks, payments ops, settlement.
All three prototypes do this. The current site says "complex systems"; visitors should not have to translate.
Trend 05
One clear primary action. Not two equal-weight buttons.
Current site has "Manifesto" / "How We Work" — neither is the action. All prototypes lead with a single decisive CTA.

Content audit · what I found

The site is light on hard numbers, on purpose. The terminal aesthetic needs to respect that.

What's real and credible: Anthony's bio (~decade Wall Street, LLM analytics → exec visibility, API platforms, cloud migration at scale, institutional ops & risk infra). The governed research infrastructure case study (analyst scripts → AWS shared libraries + client sim). The payments service detail (SEPA, FPS, FedNow, RTP, ACH, SWIFT gpi, on/off-ramp, KYC/KYB).

What's missing: Specific quantitative outcomes. The case study uses qualitative claims ("research turnaround dropped materially") not numbers. My placeholder ledger had "-79%", "+11bps", "3.4×" — credible-shaped but not defensible.

What I did: Round 02 swaps numeric metrics for qualitative status badges — SHIPPED, EXEC VIS., STP ↑, AT SCALE, CONTROLLED, EMBEDDED. These are defensible against the source content. The terminal aesthetic still reads, but you're not overclaiming.

Action items if we ship this: (1) Get permission to quote one or two real metrics from real clients. (2) Write the operator notes for the LLM analytics platform engagement — it's the strongest unwritten story. (3) Decide whether the mandate IDs (M-001 to M-006) should be real chronological order or invented.
